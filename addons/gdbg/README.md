# Godot Debug Bridge Addon

**Status: pre-alpha / repository scaffold**

This directory is reserved for the GDBG runtime addon distributed at
`addons/gdbg/`. The addon is intended to connect GDBG tooling to a running Godot
game without requiring the Godot Editor to be open.

The current `plugin.gd` is only a valid, empty `EditorPlugin` shell. No runtime
bridge functionality is implemented in this scaffold.

This README and the adjacent MIT License are kept inside the addon directory so
the addon can later be packaged independently for the Godot Asset Library.
